# energy_mod_ISEL_MIX5
Dépôt pour le module "Optimisation pour les réseaux multi-sources" (Slides, notebooks PyPSA et projet)

# Slides 
contient les slides de cours en .pptx et .pdf
Le cours est très largement basé sur le cours de Tom Brown (2020) "energy system modelling" at KIT. 

# tds
Les tds sont sous forme de jupyter notebooks, en version énoncé et version corrigé. 

Ils peuvent être ouverts localement dans un environnement avec jupyter lab ou un IDE adapté (VS code, spyder-notebook), ou dans un cloud via google collab. 
    - Local: créer un environnement dédié. Des packages seront à installer au fur et à mesure (pypsa principalement)
    - Cloud: aucun environnement à créer. Les packages doivent être ré-installlé à chaque début de session

Les tds sont basés sur des exemples de la documentation PyPSA et sur le cours de Fabian Newmann "data science for energy modelling" at TU Berlin.
